# Cube Container with a Prism – Water Simulation

Interactive 3D app (Three.js) for NDM1B Ch13 *Try It Yourself 15*: a 20 cm cubical container with a solid 4 × 10 × 20 cm prism fixed inside (4 faces free, 2 faces joined to the container walls).

- Rotate the container (on a faint table) freely in mid-air; 3D / front / top / right views; back-to-start button
- Pour water until it overflows; **Pause time** to freeze the water (and hide the stream) and inspect its shape from any angle
- English / 中文

Open `index.html` in a browser, or visit the GitHub Pages site.
